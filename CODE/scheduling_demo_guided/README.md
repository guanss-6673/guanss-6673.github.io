# 排产多步骤引导式 Demo（独立版本）

本目录是独立于 `CODE/scheduling_demo_wizard/` 的新版本，按《制造业生产计划排程需求说明模板》重构为 7 页采集流程。

## 7 步流程

1. 任务情况说明 + 任务目标要求（同页，含默认值，可改可不改）
2. 订单信息（概括输入 + 提示 + 示例 + 多文件上传）
3. 工序信息（概括输入 + 提示 + 示例 + 多文件上传）
4. 工作中心信息（概括输入 + 提示 + 示例 + 多文件上传）
5. 员工信息（概括输入 + 提示 + 示例 + 多文件上传）
6. 约束条件 + 特殊约束补充（自由输入）
7. 输出（输出要求说明 + 结构化需求摘要导出）

## 设计约束（已落实）

- 固定场景：生产排程
- 固定目标：所有订单按期交付
- 第二到第五页聚焦排产建模输入
- 个性化差异（如换模、并行限制等）放在第六页统一补充
- 不做字段完整性拦截，允许直接跳转下一步
