任务情况说明 + 任务目标要求

任务情况与目标均为固定项，默认可直接使用。

提示

  • 本页为固定项，无需填写即可进入下一步。
  • 若需补充个性化背景，请写在“约束条件与特殊约束补充”页。

示例

例如：宝峰集团制造车间需完成一批订单的加工任务。从4月3日开始，共有5个订单。

例如：任务要求如下：按照订单交期倒排各工序完工时间，按照工序完工时间倒排原材料采购到达时间，在确保订单交期前提下优化设备与员工时间。

订单信息

先填总体概括，再上传一个或多个订单表。

提示

  • 先在“订单信息概括”中写总订单数、交期分布和开工窗口。
  • 订单表建议至少包含：订单号、生产代号、生产数量、交货期、下单时间、紧急程度。
  • 订单号建议按下单日期顺序编号；紧急程度0为最低，数字越大越高。

工序信息

先填工序总体概括，再上传工序路线表或补充文件。

提示

  • 工序表需能唯一表达“先后顺序 + 资源需求 + 工时”。
  • 建议至少填写：工作中心、工序号、工序名称、工种、工时、前置工序。
  • 工时单位统一为小时；前置工序按工序号填写，便于自动识别顺序。

工作中心信息

先填工作中心总体概括，再上传多个工作中心相关文件。

提示

  • 工作中心用于承载设备资源，每道工序必须能映射到对应中心。
  • 建议填写完整的中心分类、名称、编号，避免同名中心冲突。

员工信息

先填员工总体概括，再上传员工技能与排班相关文件。

提示

  • 员工信息需覆盖“人员-中心-技能”关系，确保每道工序可分配人员。
  • 建议标明多技能员工，便于跨工序或跨中心调度。
  • 员工标准工时为7.5小时/天，可加班，但建议注明加班上限。

日历与班次例外

本页仅收集可结构化的日历/班次变化，其他差异项统一放在第6页“特殊约束补充”。

提示

  • 建议按“日期-对象-类型-时间段-影响范围”结构记录。
  • 类型可用：停工、停机、停班、调班、加班、限产。
  • 其他差异项（换模、到料、设备偏好等）请写在第6页“特殊约束补充”。

约束条件与特殊约束补充

先写通用硬约束，再补充工厂个性化规则。

提示

  • 本框建议优先填写必须满足的硬约束，确保排产结果可执行。
  • 建议一条约束一行，使用“1. 2. 3.”编号，便于模型解析。
  • 每条约束尽量写清楚对象、条件和限制动作。
  • 涉及时间、产能、工时时，尽量补充单位和时间范围。
  • 优化策略可写在“输出”页，个性化规则（换模、并行限制、优先级）写在右侧“特殊约束补充”。

示例（通用约束 + 特殊约束）

通用约束示例：

  • 每个订单的工序必须按给定顺序执行，前一道工序完成后才能开始下一道。
  • 同一设备同一时刻只能加工一个任务。
  • 一旦开始加工，必须连续完成，不可中断。

特殊约束示例：

  • 某些产品换模时间较长。
  • A工序和B工序不能并行。
  • 某些订单优先级更高。
  • 夜班不能安排某些工序。
  • 某些物料周三以后才到。

输出

输出固定为排程表，直接生成结构化需求摘要即可。

提示

  • 本页为固定输出项，无需填写即可生成结果。
  • 若有额外输出偏好，可在“约束条件与特殊约束补充”页说明。

示例

  • 生产计划表示例字段：生产计划单号、对应订单号、批次号、生产数量、计划开工时间、计划完成时间、交期。
  • 工序明细表示例字段：工序单号、对应生产单号、工序名称、工作中心、分配员工、开工时间、完成时间、总用时。
  • 产线负荷表示例字段：工作中心、工序、开始时间、结束时间、设备负荷率。
  • 人员排班表示例字段：工作中心、人员编号、人员姓名、工序、开始时间、结束时间。
